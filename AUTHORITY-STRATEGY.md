## 🔍 Content Quality Gates

**Every piece must pass:**

1. **Uniqueness Test:**
   - "Does this exist elsewhere?" → If yes, add unique angle/data
   
2. **Depth Test:**
   - Word count: 5K+ for pillar, 2K+ for supporting
   - Research hours: 5+ hours minimum
   
3. **Actionability Test:**
   - "Can reader implement this immediately?"
   - Must include: examples, tools, templates
   
4. **E-A-T Test:**
   - Expertise: Is author/site qualified?
   - Authority: Do others cite us?
   - Trust: Sources cited, methodology clear?

5. **Link Magnet Test:**
   - "Would authority sites link to this?"
   - If not, why not? Fix it.

## 📈 SEO Strategy (Long-tail + E-A-T Focus)

### **Keyword Research (MANDATORY for every piece):**

**Step 1: Identify 20-30 seed keywords**
- NOT generic ("IA España" too broad)
- Specific problems/use cases
- Commercial intent preferred

**Step 2: Filter by sweet spot**
- Search volume: 100-5,000/month
- Keyword difficulty: 0-30 (achievable)
- Intent: commercial > informational

**Step 3: Cluster keywords (10-15 per post)**
- Primary: 1 main keyword
- Secondary: 5-7 related
- Long-tail: 5-7 specific

**Step 4: Map to content structure**
- Each keyword = section in post
- Natural integration (no stuffing)
- H2/H3 = keyword variations

**Examples good keywords:**
```
✅ "mejor herramienta IA ecommerce español"
✅ "cuanto cuesta implementar IA pyme"
✅ "chatgpt vs claude español comparativa"
✅ "automatizar atención cliente whatsapp IA"
✅ "generar contenido SEO con IA herramientas"
✅ "roi inteligencia artificial retail españa"
```

**Avoid:**
```
❌ "IA España" (too generic, impossible to rank)
❌ "ChatGPT" (single-word, too competitive)
❌ "Inteligencia artificial" (too broad)
```

### **On-Page SEO:**
- Keyword in title, H1, first 100 words
- Keyword variations in H2s/H3s
- Semantic keywords throughout
- Original images/charts (alt text optimized)
- Schema markup (Article, FAQ, HowTo, Dataset)
- Internal linking (keyword-based anchors)

### **Off-Page:**
- Outreach to Spanish tech media
- Guest posts on authority sites
- HARO responses (expert quotes)
- LinkedIn thought leadership
- Twitter threads with data
- Reddit/HN when relevant

### **Technical:**
- Fast loading (< 2s)
- Mobile-first
- Core Web Vitals optimized
- Structured data (JSON-LD)
- XML sitemap
- robots.txt optimized
