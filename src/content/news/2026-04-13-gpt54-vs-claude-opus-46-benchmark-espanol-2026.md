## Metodología: Cómo Hicimos Este Benchmark

Antes de ver resultados, necesitas saber cómo los conseguimos. **Transparencia total**.

### Configuración del Test

**Período de prueba:** Enero 15 - Febrero 28, 2026 (6 semanas)

**Modelos testeados:**
- **GPT-5.4** (OpenAI) - Versión lanzada diciembre 2025
- **Claude Opus 4.6** (Anthropic) - Versión lanzada enero 2026

**Parámetros de configuración:**
- Temperatura: 0.7 (para todos los tests creativos)
- Temperatura: 0.2 (para tests técnicos/precisión)
- Max tokens: 2000 (salvo tests específicos de long-form)
- Top-p: 0.9
- Frequency penalty: 0.3

**Variantes de español testeadas:**
1. **Español peninsular** (España) - 18 tests
2. **Español mexicano** - 19 tests
3. **Español rioplatense** (Argentina/Uruguay) - 18 tests
4. **Español colombiano** - 18 tests

### Categorías Evaluadas

Dividimos los tests en **8 categorías** que importan para PyMEs:

| Categoría | Tests | Peso | Por Qué Importa |
|-----------|-------|------|-----------------|
| **Atención al Cliente** | 12 | 20% | Respuestas a clientes, quejas, dudas |
| **Copywriting** | 11 | 18% | Emails, ads, landing pages |
| **Análisis de Datos** | 8 | 12% | Interpretar ventas, métricas, tendencias |
| **Generación de Contenido** | 10 | 15% | Blogs, redes sociales, newsletters |
| **Tareas Técnicas** | 9 | 13% | Código, fórmulas, automatizaciones |
| **Traducción & Localización** | 8 | 10% | Adaptar contenido entre variantes |
| **Razonamiento Complejo** | 8 | 7% | Estrategia, planificación, decisiones |
| **Velocidad & Costo** | 7 | 5% | Tiempo de respuesta, tokens usados |

**Total: 73 tests documentados**

### Sistema de Puntuación

Cada test recibió una puntuación de **0-10** en 4 dimensiones:

1. **Precisión** (40%) - ¿Es correcta la respuesta?
2. **Naturalidad** (30%) - ¿Suena como español nativo?
3. **Utilidad** (20%) - ¿Puedes usar esto sin editar?
4. **Velocidad** (10%) - ¿Cuánto tardó?

**Ejemplo de scoring:**

```
Test: Responder queja de cliente (España)
Prompt: "Un cliente dice que el pedido llegó roto. Escribe respuesta profesional pero cercana."

GPT-5.4:
- Precisión: 9/10 (aborda todo)
- Naturalidad: 8/10 (un par de frases raras)
- Utilidad: 9/10 (casi listo para enviar)
- Velocidad: 9/10 (2.3 segundos)
→ Score final: 8.7/10

Claude Opus 4.6:
- Precisión: 10/10 (perfecto)
- Naturalidad: 9/10 (español impecable)
- Utilidad: 8/10 (un poco largo)
- Velocidad: 7/10 (4.1 segundos)
→ Score final: 8.9/10
```

### Equipo Evaluador

No fui solo yo. Reclutamos **12 evaluadores nativos**:

- 3 de España (Madrid, Barcelona, Valencia)
- 3 de México (CDMX, Guadalajara, Monterrey)
- 3 de Argentina (Buenos Aires, Córdoba, Rosario)
- 3 de Colombia (Bogotá, Medellín, Cali)

**Perfil:** Dueños de PyMEs, freelancers o managers con experiencia usando IA.

Cada test fue evaluado por **3 personas** (una de cada región cuando era relevante). Promediamos las puntuaciones.

### Limitaciones del Estudio

**Seamos honestos sobre qué NO cubre este benchmark:**

❌ **No testeamos casos extremos** - Prompts de 50,000 palabras, idiomas raros, código ultra-complejo
❌ **No evaluamos ética/seguridad** - Ese es otro artículo
❌ **No incluimos todos los dialectos** - Faltan Chile, Perú, Venezuela, etc.
❌ **Contexto limitado** - Tests con 0-2 mensajes previos, no conversaciones de 50 turnos
❌ **Subjetividad** - "Naturalidad" tiene componente subjetivo inevitable

**Pero:** Para el 80% de casos de uso de una PyME, estos tests son representativos.

function consolidarVentasSemanales() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var ventasSheet = ss.getSheetByName("Ventas Semana");
  var historicoSheet = ss.getSheetByName("Histórico");
  
  // Obtener datos de ventas
  var lastRow = ventasSheet.getLastRow();
  if (lastRow < 2) return; // No hay datos
  
  var datos = ventasSheet.getRange(2, 1, lastRow-1, 
  ventasSheet.getLastColumn()).getValues();
  
  // Añadir fecha a cada fila
  var fecha = new Date();
  datos.forEach(function(fila) {
    fila.unshift(fecha); // Añade fecha al inicio
  });
  
  // Pegar en histórico
  var historicoLastRow = historicoSheet.getLastRow();
  historicoSheet.getRange(historicoLastRow+1, 1, 
  datos.length, datos[0].length).setValues(datos);
  
  // Limpiar ventas semana (mantener encabezados)
  if (lastRow > 1) {
    ventasSheet.getRange(2, 1, lastRow-1, 
    ventasSheet.getLastColumn()).clearContent();
  }
}

// Configurar trigger
function crearTriggerSemanal() {
  ScriptApp.newTrigger('consolidarVentasSemanales')
    .timeBased()
    .onWeekDay(ScriptApp.WeekDay.MONDAY)
    .atHour(9)
    .create();
}
