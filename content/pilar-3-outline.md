### 6. Lecciones Aprendidas: Framework Decisión (800 palabras)

**¿Cuándo implementar IA en tu PyME?**

**Señales estás listo:**
✅ Proceso manual repetitivo >10h/semana
✅ Data histórica 6+ meses
✅ Problema definido (no vago "mejorar eficiencia")
✅ ROI estimado >200% primer año
✅ Budget 5K-15K€ (o Kit Digital aprobado)

**Señales espera:**
❌ No tienes data digitalizada
❌ Procesos caóticos (arregla primero)
❌ Equipo resistente (forma antes)
❌ Problema ambiguo
❌ Expectativas mágicas ("IA resolverá todo")

**Framework decisión 5 pasos:**

**Paso 1: Identifica bottleneck #1**
- Dónde se va más tiempo
- Dónde hay más errores
- Dónde pierdes más €

**Paso 2: Mide baseline**
- Horas/semana actuales
- Coste actual (€)
- Tasa error actual
- Ingresos/conversión actual

**Paso 3: Calcula ROI estimado**
- Herramienta/solución cost
- Tiempo ahorro estimado
- ROI = (Beneficio - Coste) / Coste × 100
- Si ROI <200% primer año → replantea

**Paso 4: Piloto pequeño (MVP)**
- 1 caso uso
- 1 equipo/área
- 1-3 meses test
- Mide resultados reales

**Paso 5: Escala si funciona**
- Replica otros equipos
- Añade casos uso complementarios
- Invierte ahorros en más automatización

**Decision tree:**
```
¿Tienes proceso repetitivo >10h/semana? 
  → SI: ¿Tienes data 6+ meses?
    → SI: ¿Budget 5K-15K€ o Kit Digital?
      → SI: ✅ IMPLEMENTA (prioridad alta)
      → NO: Busca ayudas o empieza tools low-cost (<500€/mes)
    → NO: Digitaliza data 6 meses → vuelve
  → NO: Busca otro bottleneck
```
