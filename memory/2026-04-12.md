## KEY DECISIONS & LEARNINGS

### Subagent Execution Rules (VALIDATED):
1. **Tareas pequeñas:** 900-1,500 palabras max por subagent
2. **Scope limitado:** Una cosa específica (no "escribe 3 secciones + conclusión")
3. **En paralelo:** 3-5 subagents trabajando a la vez en diferentes tasks
4. **Sin mega-tasks:** Nada de "escribe 10K palabras" o "haz todo"

**Ejemplos buenos (hoy):**
- ✅ "Write ONLY Part 2.1 (900 words)" - funcionó perfecto
- ✅ "Improve About page sections" - 40 segundos
- ✅ "Upgrade table styling CSS" - 1m9s
- ✅ "Write Intro + Methodology PILAR 2 (900 words)" - 59s

**Ejemplos malos (aprendidos):**
- ❌ "Write Parts 4+5+conclusion (3,000 words)" - subagent falló, yo completé
- ❌ (histórico) "Generate entire 10K word article" - timeout

### Gemini Imagen Configuration (WORKING):
- **SDK:** `google-genai` (NOT deprecated `google.generativeai`)
- **Model:** `imagen-4.0-fast-generate-001` ($0.02/image) o `imagen-4.0-generate-001` ($0.04)
- **Safety:** `block_low_and_above` (único válido, not `BLOCK_LOW_AND_ABOVE`)
- **Aspect ratios:** 1:1, 16:9, 9:16, 4:3, 3:4
- **Script:** `/root/.openclaw/workspace/workless-v2/scripts/generate_image_final.py`

### Mobile Responsive Rules (MANDATORY):
- **Tablas:** `overflow-x: auto`, container `max-width: 100%`
- **Imágenes:** `max-width: 100%`, `height: auto`
- **Text:** `word-wrap: break-word`
- **Touch targets:** Minimum 44x44px (WCAG 2.1 AA)
- **Typography:** 16px base mobile (nunca menor)
