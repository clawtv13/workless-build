# WorkLess AI - La Fuente Definitiva de IA en Español

## 🎯 Overview

WorkLess AI es un hub automatizado de contenido sobre Inteligencia Artificial en español, featuring:

- 📰 **Noticias** - Actualizaciones diarias del mundo IA
- 📚 **Tutoriales** - Guías prácticas paso a paso
- ⚙️ **Reviews** - Análisis de herramientas IA
- 💼 **Casos de Uso** - Implementaciones reales

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Dev server
npm run dev

# Build
npm run build

# Preview build
npm run preview
```
